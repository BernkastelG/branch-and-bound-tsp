# branch-and-bound-tsp

Решение задачи о назначении в графе на основе метода ветвей и границ.  
Курсовая работа по дисциплине «Основы автоматизации проектирования электронных средств».

## Описание

Задача о назначении заключается в поиске оптимального взаимно-однозначного соответствия между вершинами двух множеств графа так, чтобы суммарный вес назначенных рёбер был минимальным [file:1]. Такая задача часто встречается в транспортном планировании, распределении ресурсов и оптимизационных алгоритмах [file:1].

Проект реализует классический **метод ветвей и границ** для точного решения этой задачи на языке C++ [file:1] и включает вспомогательную утилиту для генерации входных данных.

## Состав проекта

| Программа | Назначение |
|---|---|
| `assignment_solver` (main.cpp) | Основное решение задачи о назначении методом ветвей и границ |
| `MatrixGen` | Генерация весовой матрицы для входного файла `MyFile.txt` — вручную или случайным образом |

## Применение

Метод ветвей и границ для задачи о назначении может использоваться, например, для:

- Распределения сотрудников по проектам с учётом их навыков
- Оптимизации маршрутов доставки и назначения транспорта пунктам назначения
- Распределения задач между станками на производственной линии
- Назначения врачей и коек пациентам
- Составления расписания игр и назначения судей

## Архитектура основного решателя

Программа построена на четырёх основных классах [file:1]:

| Класс | Назначение |
|---|---|
| `Graph` | Хранит граф и предоставляет методы работы с ним |
| `Add_mtr` | Хранит вспомогательные матрицы, используемые при наложении ограничений |
| `Answer` | Хранит матрицу итоговых назначений |
| `Algorithm` | Реализует непосредственно метод ветвей и границ |

Ключевые методы `Algorithm`:

- `branches_and_boundaries` — основной алгоритм ветвей и границ
- `comparison_min` — поиск минимальных значений по строкам и столбцам
- `comparison` — сравнение минимумов строки и столбца
- `record_file` — запись результата в файл

## MatrixGen — генератор входных данных

`MatrixGen` — небольшая утилита для подготовки файла `MyFile.txt`, который затем использует основной решатель.

Программа запрашивает у пользователя:

1. Число `N` — количество вершин в одном из множеств графа
2. Способ заполнения весовой матрицы:
   - `C` — ручной ввод всех значений матрицы с клавиатуры
   - `N` — случайная генерация значений в диапазоне от 1 до 50
   - `E` — выход из программы

Результат сохраняется в текстовый файл в формате, совместимом с `assignment_solver`: первая строка содержит число `N`, далее следует весовая матрица `N x N`.

### Сборка и запуск MatrixGen

```bash
g++ -std=c++17 -o matrix_gen MatrixGen.cpp
./matrix_gen
```

> Обратите внимание: перед сборкой укажите в коде относительный путь к выходному файлу (например, `"MyFile.txt"`) вместо абсолютного пути на локальном диске, чтобы программа корректно работала на любом компьютере.

## Формат данных

**Входные данные** (`MyFile.txt`): размер множества вершин `N` и весовая матрица графа `N x N`. Может быть подготовлен вручную или сгенерирован с помощью `MatrixGen`.

**Выходные данные** (`MyAnswer.txt`): итоговая матрица назначений — соответствие между вершинами первого и второго множества с указанием суммарного веса решения.

## Сборка и запуск основного решателя

```bash
g++ -std=c++17 -o assignment_solver main.cpp
./assignment_solver
```

Программа считывает данные из `MyFile.txt`, выполняет назначение методом ветвей и границ и сохраняет результат в `MyAnswer.txt`, дублируя вывод в консоль.

## Типовой сценарий использования

1. Запустите `MatrixGen`, задайте число вершин `N` и заполните матрицу вручную или случайно
2. Запустите `assignment_solver`, который прочитает сгенерированный `MyFile.txt`
3. Изучите результат в консоли или в файле `MyAnswer.txt`

## Пример работы

Программа выводит найденное оптимальное назначение вершин первого множества вершинам второго множества с указанием общей минимальной суммы весов, а также сохраняет результат в текстовый файл для дальнейшего использования.
